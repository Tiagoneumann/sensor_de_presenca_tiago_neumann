## Enunciado: sensor de movimento!

O sistema utiliza um sensor de presença PIR como entrada para controlar um LED como saída. Quando o sensor detecta movimento, o Arduino acende o LED e o mantém ligado por alguns segundos. Caso não seja detectado movimento, o LED permanece desligado.

- O Arduino lê o estado do sensor PIR pelo **pino digital 7**;
- Controla o LED pelo **pino digital 6**;
- Quando o sensor detecta movimento, o LED é ligado por 5 segundos;
- Quando não há detecção de movimento, o LED permanece desligado.
